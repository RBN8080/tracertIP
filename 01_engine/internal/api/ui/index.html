      Reading rules

      1. R1 Loss only at an intermediate hop with a healthy target is that router's ICMP limit, not real loss.
      2. R2 A high RTT at a hop that does not persist in the next ones is a slow router or a different return path, not the bottleneck.
      3. R3 An increase that holds to the end is where the real cost is.
      4. R4 Router name against physics: physics wins.
      5. R5 A hop that does not answer is a gap; the path is not broken.
      6. R6 Anycast never measures the distance to a continent.

      Locations are inferences; the return path is not visible from one vantage point.
