      Cómo interpretar la ruta
      • Un salto intermedio puede limitar sus respuestas ICMP aunque el destino siga respondiendo.
      • El RTT mide ida y vuelta desde el nodo. La ruta de retorno y la ubicación física son inferencias.
      • Una ubicación incompatible con el límite físico se marca en los indicadores. Con anycast, una IP puede responder desde distintos sitios.
